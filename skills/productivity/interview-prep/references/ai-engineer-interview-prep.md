# AI Engineer Interview Prep Reference

## Role: AI Engineer (not ML Engineer)

**Key distinction:**
- AI Engineer = deploying AI systems, building pipelines, MLOps, APIs, agent systems, production deployment
- ML Engineer = research, model training, algorithm development

## Priority Topics (in order)

1. **LLM fundamentals** — transformers, attention mechanism, tokenization, embeddings, context windows
2. **RAG systems** — vector databases, retrieval strategies, chunking, reranking, hybrid search
3. **Prompt engineering** — few-shot, chain-of-thought, structured outputs, system prompts
4. **AI agent frameworks** — LangChain, LlamaIndex, CrewAI, AutoGen, tool use, agent loops
5. **Model deployment** — FastAPI, Docker, ONNX, TensorRT, vLLM, model serving patterns
6. **Fine-tuning** — LoRA, QLoRA, RLHF basics, parameter-efficient methods
7. **MLOps** — MLflow, DVC, model versioning, CI/CD for ML, experiment tracking
8. **System design for AI** — scaling inference, caching, load balancing, batching, async processing
9. **Vector DBs** — ChromaDB, Pinecone, Weaviate, FAISS, indexing strategies
10. **Evaluation** — BLEU, ROUGE, perplexity, human eval, LLM-as-judge

## Resume Keywords to Target

AI Engineer, LLM, RAG, Fine-tuning, Python, FastAPI, Docker, PyTorch, MLOps, Vector DB, Prompt Engineering, AI Agents, Model Deployment, LoRA, vLLM, LangChain

## Project Talking Points

When prepping for interviews, always reference these real projects:
1. **AI Text Summarizer** — T5-small fine-tuned on SAMSum (4000 dialogues, 6 epochs), deployed on Render via HuggingFace Inference API. GitHub + HuggingFace.
2. **GI Adenocarcinoma CNN** — Medical image classification with CNN
3. **Hermes Agent Setup** — Custom workflow engine, MCP servers, cron jobs, multiple skills

## Companies to Target

- Product startups (Series A/B) — higher equity, AI-first
- Service companies with AI teams — TCS, Infosys, Wipro (baseline 6 LPA)
- Mid-size product companies — 6-10 LPA range
- AI/ML specific startups on LinkedIn and Instahyre

## Daily Non-Negotiables

- Apply to at least 3 AI Engineer jobs
- Study/build from the priority topics list
- Practice DSA (Python) — 1 problem minimum
