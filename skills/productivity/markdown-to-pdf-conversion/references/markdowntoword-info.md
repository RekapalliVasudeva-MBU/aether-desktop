# markdowntoword.io Reference

markdowntoword.io provides online tools for converting between Markdown, Word, PDF, and other formats.

## Markdown to PDF Converter
- URL: https://markdowntoword.io/tools/markdown-to-pdf
- Functionality: Converts Markdown (.md) files to PDF documents
- Process: 
  1. Upload a Markdown file
  2. Click "Download as PDF" to convert and download
- Output: Standard PDF file with preserved formatting

## Notes
- The service is free to use
- No account required for basic conversions
- Preserves basic Markdown formatting (headers, lists, code blocks, etc.)
- For complex documents, review the output PDF for formatting accuracy

## Privacy
According to the site's privacy policy (as of knowledge cutoff), uploaded files are processed temporarily and not stored permanently. However, for sensitive documents, consider using offline conversion methods.
