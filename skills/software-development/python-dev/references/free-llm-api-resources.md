# Free LLM API Resources

**Source:** https://github.com/cheahjs/free-llm-api-resources
**Last verified:** June 2026

Curated list of free/trial LLM API providers. Useful when users ask "what free LLMs can I use?" or need fallback options.

## Key Providers with Free Tiers

| Provider | Free Tier | Notes |
|----------|-----------|-------|
| OpenRouter | Limited free models | Aggregates many models, pay-per-use |
| Google AI Studio | Free tier available | Gemini models, rate-limited |
| NVIDIA NIM | Free tier | GPU-accelerated inference |
| Mistral | Free tier | Mixtral, Mistral models |
| HuggingFace Inference | Free tier | Open-source models, rate-limited |
| Groq | Free tier | Ultra-fast inference (LLaMA, Mixtral) |
| Cohere | Free tier | Command R models |
| GitHub Models | Free for GitHub users | Various open models |
| Cloudflare Workers AI | Free tier | Runs on Cloudflare edge |

## Notable Free Models (as of June 2026)

- **deepseek-v4-flash** — fast, capable
- **gemma-4-26b** — Google's open model
- **nemotron-3-super-120b** — NVIDIA's large model
- **kimi-k2.6** — Moonshot AI
- **glm-4.5-air** — Zhipu AI
- **qwen3-coder** — Alibaba's coding model

## When to Reference This

- User asks for free LLM alternatives
- Primary provider is rate-limited or down
- User wants to experiment without spending
- Building cost-optimized RAG/AI pipelines
