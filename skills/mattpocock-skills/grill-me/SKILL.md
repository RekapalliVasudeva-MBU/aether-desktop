# Grill Me

Interview the user relentlessly about every aspect of their plan until reaching shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions one at a time, waiting for feedback before continuing.

If a question can be answered by exploring the codebase, explore the codebase instead.

## When to Use

- Before starting a new feature or project
- When the user says "grill me" or "stress-test my plan"
- When there's ambiguity about requirements or architecture
- Before writing any code for a complex task

## Output

A clear, resolved plan with all major decisions documented. Both user and agent should have shared understanding before proceeding to implementation.
